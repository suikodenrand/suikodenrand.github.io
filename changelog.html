Suikoden I inventory and quick start

All four features are on by default. In launcher 1.0.7, open Suikoden I → Quality of Life to switch them individually or choose Disable all four. Select Apply settings with the game closed.

  • Roc’s Warehouse. Once Roc has joined, open the field Items menu. Roc’s Warehouse appears just below Party Items, with the usual deposit and withdrawal options.
  • Shared battle items. Use an item from any living fighter in the active party, including an Unbalanced ally. The list shows the carrier and remaining charges. The acting fighter spends the turn and the carrier spends the charge.
  • Optimize equipment. In Equipment, select a fighter and press Up from headgear. Optimize equips their highest-defense legal loadout and keeps current gear on a tie. The default uses loose gear from the party and, once Roc joins, his warehouse. Press Left or Right to change sources. Gear worn by teammates stays with its owner.
  • Viktor quick start. The two teammates already traveling with Tir now start at his checkpoint level, normally 7. Each uses their own stat growth and recalculated spell charges.

CTB preview 0.5.2

CTB gives each living hero and enemy an individual turn based on SPD. The bottom-center timeline forecasts up to eight actions. Highlight a command to preview when that fighter should act again. Wait, Defend, Attack, Item and different rune tiers have different recovery times.

  • Choose the next ally’s action from the full command menu while the previous animation plays. Consecutive enemy turns move faster, and a failed Run returns to CTB turn order.
  • Field emblems appear above enemy sprites and match the timeline and target list. Break can delay an enemy’s next turn. Reserve Rally lets eligible reserves advance an ally’s next turn.
  • The tuning editor supports individual SPD overrides, separate Break delays and optional solo-boss or normal-encounter scaling. The tested solo-boss setup uses a 75% party / 25% recommended-level blend and caps each fighter’s contribution at their average SPD four levels above the recommendation, plus equipment. It targets about one boss attack per three normal party attacks. Solo-boss Break defaults to 25%.

Standard battles are the default. CTB applies to regular S1 battles. Suikoden II, duels and army battles use their usual systems. Enable CTB or return to standard battles →

Stars of Destiny 0.14.5

More reliable campaign saves, party changes and recruitment, plus launcher 1.0.6. Existing seeds keep their character and treasure assignments.

Campaign saves & parties

  • Suikoden I. Routine gaps while the game changes party formation no longer block future saves. Fixed parties refresh the underlying character record before battle, and recruits receive pending starting-weapon updates during scene transitions.
  • Ordinary S1 saves continue to work. If a randomized save still has equipment or treasure settings but its campaign binding is missing, the randomizer asks for the matching backup. A rejected randomized save also stops the optional Suikoden Fix editable copy from replacing it.
  • Suikoden II. Each new recruit receives the starting equipment that fits. A full bag postpones only recruits who need space. Character graphics refresh when the game replaces them and can be reused across reloads.
  • Saving the same S2 snapshot again preserves its original campaign settings. Conflicting policies can no longer replace an older binding.

Launcher & recovery

  • Launcher 1.0.6 checks seeds against the way the game reads and writes them. Presets use the game's setting names, and applying settings checks changes made by another open launcher.
  • Save & launch game starts the installation you selected. Activating the optional S1 ATB preview keeps any unapplied settings edits in the launcher.
  • Setup prints its recovery path when installation begins. Restore can recover interrupted installations and remove matching package files after a game update. It keeps older loader and plugin binaries in the backup when the game build has changed.

Upgrading

Close the game and launcher, then back up Save and BepInEx/config together before running setup. Keep the backup path that setup prints. Optional Suikoden I ATB is the public 0.10.1 preview and remains off by default.

New in 0.14.4: balanced joining equipment

  • Shuffled recruits default to the original story role's complete starting inventory, including armor, accessories and consumables.
  • Gear a replacement cannot wear is exchanged for comparable compatible equipment. The replacement keeps its weapon identity and runes; joining weapon levels remain a separate choice.
  • The option works in Character shuffle, Fixed roster and Random roster in both games. Choose the replacement's own starting inventory to keep the previous behavior.
  • First-join history and the chosen policy are saved with the campaign. Later recruitment preserves acquired gear. Existing campaigns are not retrofitted.
  • Launcher 1.0.4 and the website preset builder expose the new per-game option.

Initial S1 recruitment and saved-loadout checks passed. A native reload of the new save and wider recruitment coverage remain pending.

Included from 0.14.3: both games

  • Suikoden II now joins Suikoden I with seeded character shuffle, five chosen companions, a seeded random roster, optional protagonist shuffle and a quick start at Viktor’s camp.
  • The two engines share one in-game interface while keeping each game’s settings, seeds and saved campaign bindings separate.
  • Shuffled names, portraits, party and battle appearances follow the replacement fighters. Story-role recruitment requirements remain native.
  • Supported English dialogue mentions use shuffled names. The curated replacement system preserves native custom-name tokens and leaves unsupported or ambiguous lines unchanged.
  • Native shuffled-character Unite previews work from the actual fighters in the party, including those filling unrelated story roles. Native conditions, targeting, animations and action use are retained.
  • The F6 display is hidden by default. Visible modes use text without the black background; F6 cycles Full, Compact and Hidden.

Joining weapons

New in 0.14.3: Suikoden II’s fresh default follows Riou’s current weapon level at a replacement’s first party join, with a seeded −3 to +3 modifier, including a possible exact match. This mirrors Suikoden I’s Tir-based default.

Both games also offer matching the original story character or starting at weapon level 1. The replacement keeps its own weapon identity, and the adjustment happens once. Saved campaigns retain their weapon policy and earned sharpening. Protected setups retain native handling; S2 natural weapons stay at level 0.

Launcher & full installation

  • The Windows launcher manages per-game seeds, modes, companions, quick starts, joining inventory, joining weapons, dialogue, interface, treasure, optional ATB and included Suikoden Fix settings.
  • JSON settings presets can be saved and loaded. The website can prepare a basic campaign preset; load it with the launcher’s Load settings… button, then select Apply settings before starting New Game.
  • The NSIS package includes BepInEx 6 IL2CPP x64, Suikoden Fix, the launcher and their separate private .NET runtimes. The first modded launch still downloads Unity reference libraries.
  • Setup verifies the supported game build, detects known duplicate or conflicting plugins, preserves existing configurations and saves, and records transaction backups. The installed Restore.cmd tool can undo an installation transaction.
  • The rebuilt package contains extracted upstream source folders and notices, with no nested source ZIPs.

Optional Suikoden I previews

Treasure shuffle

A deterministic campaign-seeded shuffle changes ordinary chest item rewards while retaining protected recruitment items, potch, special rewards and native chest open-state handling. It is off by default and controlled through the launcher.

Active-time battles

The optional S1 ATB plugin uses filling SPD meters, DEX influences, individual native command menus, targeting and visible native meters. Ready heroes can queue actions while other actions play, and queued attacks can retarget a surviving enemy in range.

ATB is a separate optional component and is installed disabled. Turn off S1 shuffled Unites before enabling ATB. S2 ATB, S2 chest shuffle and Nuzlocke are not included.
