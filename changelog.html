One randomizer for both games

  • Suikoden II now joins Suikoden I with seeded character shuffle, five chosen companions, a seeded random roster, optional protagonist shuffle and a quick start at Viktor’s camp.
  • The two engines share one in-game interface while keeping each game’s settings, seeds and saved campaign bindings separate.
  • Shuffled names, portraits, party and battle appearances follow the replacement fighters. Story-role recruitment requirements remain native.
  • Supported English dialogue mentions use shuffled names. The curated replacement system preserves native custom-name tokens and leaves unsupported or ambiguous lines unchanged.
  • Native shuffled-character Unite previews work from the actual fighters in the party, including those filling unrelated story roles. Native conditions, targeting, animations and action use are retained.
  • The F6 display is hidden by default. Visible modes use text without the black background; F6 cycles Full, Compact and Hidden.

Joining weapons

New in 0.14.3: Suikoden II’s fresh default follows Riou’s current weapon level at a replacement’s first party join, with a seeded −3 to +3 modifier, including a possible exact match. This mirrors Suikoden I’s Tir-based default.

Both games also offer matching the original story character or starting at weapon level 1. The replacement keeps its own weapon identity, and the adjustment happens once. Saved campaigns retain their weapon policy and earned sharpening. Protected setups retain native handling; S2 natural weapons stay at level 0.

Launcher & full installation

  • The Windows launcher manages per-game seeds, modes, companions, quick starts, joining weapons, dialogue, interface, treasure, optional ATB and included Suikoden Fix settings.
  • JSON settings presets can be saved and loaded. The website can prepare a basic campaign preset; load it with the launcher’s Load settings… button, then select Apply settings before starting New Game.
  • The NSIS package includes BepInEx 6 IL2CPP x64, Suikoden Fix, the launcher and their separate private .NET runtimes. The first modded launch still downloads Unity reference libraries.
  • Setup verifies the supported game build, detects known duplicate or conflicting plugins, preserves existing configurations and saves, and records transaction backups. The installed Restore.cmd tool can undo an installation transaction.
  • The rebuilt package contains extracted upstream source folders and notices, with no nested source ZIPs.

Optional Suikoden I previews

Treasure shuffle

A deterministic campaign-seeded shuffle changes ordinary chest item rewards while retaining protected recruitment items, potch, special rewards and native chest open-state handling. It is off by default and controlled through the launcher.

Active-time battles

The optional S1 ATB plugin uses filling SPD meters, DEX influences, individual native command menus, targeting and visible native meters. Ready heroes can queue actions while other actions play, and queued attacks can retarget a surviving enemy in range.

ATB is a separate optional component and is installed disabled. Turn off S1 shuffled Unites before enabling ATB. S2 ATB, S2 chest shuffle and Nuzlocke are not included.

Upgrading & testing

Close the game and launcher, back up Save and BepInEx/config together, then run the new full installer. Existing settings and saved campaign policies are preserved. Choose the new Riou-based policy in the launcher for new S2 campaigns if your existing configuration retains another option.

The package passed 24 installer checks, including fresh installation, upgrades, rollback and restore. Runtime tests and representative in-game checks cover the combined randomizer; every scripted encounter and Unite combination has not been played through. The optional S1 treasure and ATB features remain experimental, and native first-join playtesting of the new Riou weapon policy is pending.
