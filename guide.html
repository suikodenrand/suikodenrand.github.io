What you need

  • Your own Steam copy of Suikoden I & II HD Remaster on Windows x64.
  • An internet connection for the first BepInEx launch, when Unity reference libraries are downloaded.

The full package includes BepInEx 6 IL2CPP x64, Suikoden Fix, the combined randomizer, the Windows launcher and their private .NET runtimes. You do not need a separate loader download, SDK or compiler.

Back up the game’s Save and BepInEx/config folders together outside the game directory. Keep the pair together for each campaign.

Installation

  1. Close the game and launcher

    Wait for Steam to show that the game has stopped. Make the paired save and configuration backup first if you already play with mods.

  2. Run the full installer

    Download the 0.14.3 setup EXE, or download the full ZIP with offline instructions, notices and extracted upstream sources. If using the ZIP, extract it first and open Stars-of-Destiny-0.14.3-Nexus-Setup.exe.

    Choose the folder containing Suikoden I and II HD Remaster.exe and GameAssembly.dll. In Steam, use Manage → Browse local files to find it. Setup checks the supported game build and reports conflicting loader or duplicate plugin files.

  3. Choose whether to install ATB

    Leave Experimental S1 ATB (installed disabled) unchecked for standard turn-based battles. Selecting it installs the separate preview; it does not enable it. See optional features before turning it on.

  4. Open the launcher and apply your settings

    Open Stars of Destiny Preview in the current user’s Start Menu, or run <game>/StarsOfDestiny Launcher/StarsOfDestiny.Launcher.exe. Choose Suikoden I or II, then set your seed and options. To use a website preset, follow the steps below.

    With the game closed, select Apply settings or Save & launch game.

  5. Let first-run setup finish

    Keep Steam and internet access available while BepInEx downloads reference libraries and generates interop files. The first launch can take several minutes; wait for the title screen.

  6. Start your adventure

    Choose the matching game and start New Game to use the new seed, roster, start and weapon policy. The F6 panel starts hidden; press F6 to cycle its text through Full, Compact and Hidden views.

Upgrading an existing installation

Setup preserves existing settings, campaign bindings, saves and unrelated plugins. Fresh defaults do not overwrite your choices. Leaving ATB unchecked also preserves an ATB installation that is already present. Keep the transaction backup path printed by setup so you can undo that installation later.

Use a website settings preset

  1. In the website settings builder, choose the game, seed, mode, companions, start and joining weapon policy, then download the settings preset JSON.
  2. Install 0.14.3 and open its launcher. Choose Load settings… and select the downloaded JSON.
  3. Select the game you configured, review its options, then choose Apply settings or Save & launch game while the game is closed.
  4. Start a New Game in that game.

The preset carries the selected game’s basic campaign choices. The launcher provides the rest of the settings, including dialogue, interface, treasure and optional ATB controls. Loading a preset merges its supplied options; it does not replace your other game’s settings or saved campaign bindings.

Downloading a preset does not apply it. The full installer installs its defaults or preserves existing configurations; it does not read a loose configuration file placed beside the setup EXE.

Seeds & saved games

Suikoden I and II use separate seeds, mappings and settings. Seed, roster, quick start and joining weapon choices apply to new campaigns. Existing randomized saves restore their own seed, cast and weapon policy, including earned sharpening.

Starting New Game may replace the shared autosave. Make a manual save and keep a paired backup of Save and BepInEx/config first. Do not delete campaign sidecars to force a different seed or weapon policy onto a saved run.

Ordinary saves are not converted into new randomized campaigns. If a randomized save has lost its binding, restore the matching configuration backup rather than generating a new campaign over it.

Modes, starts & joining weapons

  • Character shuffle assigns eligible combat fighters to story roles using your seed. Protagonist shuffle is optional.
  • Fixed roster reserves the protagonist and lets you choose five different companions. Story progression still determines how many active party slots are available.
  • Random roster uses the seed to choose five companions alongside the protagonist.

Recruitment requirements and story roles stay native. Names, portraits, party and combat appearances follow the replacements; some custom scene animations retain native handling. Supported English dialogue mentions use shuffled names, while ambiguous references, other languages and unsupported messages stay original.

Native shuffled-character Unite previews follow the actual fighters in your party, including replacements occupying unrelated story roles. Participants still need to satisfy each attack’s native conditions. Use normal turn-based battles for these Unites.

Optional features

Suikoden I treasure shuffle

Experimental and off by default. In the launcher’s Treasure settings, enable both the global allowance and the option for new campaigns or saves without a chest policy. Protected recruitment items, potch and special rewards stay original. A save that already has a disabled chest policy needs that policy reset through the selected-save manager before reloading; the manager keeps a backup.

Turning off the global allowance pauses the shuffle without removing earned items or closing opened chests. Suikoden II chest randomization is not included.

Suikoden I active-time battle preview

Install the optional ATB component, then open the launcher’s Battle & ATB tab. Turn off Enable shuffled-character Unite attacks for S1 before enabling ATB. Apply and relaunch. Heroes and enemies use SPD meters, with DEX contributing to enemy charge and randomized opening charge; native command menus and targeting are used.

To return to standard battles, disable ATB, then re-enable shuffled Unites if wanted. ATB and shuffled Unites cannot run together. Suikoden II retains native turn-based combat. Nuzlocke is not included in this package.

Troubleshooting & restore

First launch is slow, or no F6 panel appears

Wait for BepInEx’s first-run reference download and interop generation. Check BepInEx/LogOutput.log for progress or errors. Once in-game, focus the window and press F6: hidden is the default, and visible modes show text without a black box. The launcher can change the startup view.

My seed, quick start or joining weapons did not change

Load the website JSON with Load settings…, apply it in the launcher with the game closed, and start New Game in the selected game. Existing saves keep their bound seed, policy and progress. Upgrades preserve existing configuration choices, so select Riou’s ±3 option explicitly for a new S2 campaign if an older policy was retained.

Setup reports a loader conflict or duplicate plugin

Keep a backup before changing anything. Do not mix different BepInEx core or runtime versions. A renamed folder under BepInEx/plugins still loads its DLLs; duplicate randomizer, ATB or Fix copies must be moved outside that plugins tree. Follow the reported conflict rather than bypassing setup’s checks.

How do I undo this installation?

Close the game and launcher. Open the Start Menu support shortcut or <game>/StarsOfDestiny Setup, then run Restore.cmd. Supply the FullPreview-* transaction backup path printed by setup under <game>/SRR-Backups. Restore checks the current files before reversing one installation transaction. If a later transaction or edit conflicts, follow its message or undo later transactions first.

Restore does not rewind gameplay or undo later settings edits. For a whole campaign restore, use its paired Save and BepInEx/config backup. Launcher configuration backups are under BepInEx/config/StarsOfDestiny.Launcher/backups.

This release includes previews that need wider playtesting, particularly scripted battles and Unite combinations. Riou-based first-join weapon handling has managed test coverage; native playtesting of that new option is pending. When reporting an issue, include S1/S2, versions, seed, mode, scene and BepInEx/LogOutput.log.
