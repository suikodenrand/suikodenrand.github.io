What you need

  • Your own Steam copy of Suikoden I & II HD Remaster on Windows x64.
  • An internet connection for the first BepInEx launch, when Unity reference libraries are downloaded.

The full package includes BepInEx 6 IL2CPP x64, Suikoden Fix, the combined randomizer, Windows launcher 1.0.7 and their private .NET runtimes. You do not need a separate loader download, SDK or compiler.

Back up the game’s Save and BepInEx/config folders together outside the game directory. Keep the pair together for each campaign.

Installation

  1. Close the game and launcher

    Wait for Steam to show that the game has stopped. Make the paired save and configuration backup first if you already play with mods.

  2. Run the full installer

    Download the 0.14.6 setup EXE and run it. The full installer includes the loader, launcher, mod components, offline instructions and required notices. For installation without setup, follow the manual ZIP instructions.

    Choose the folder containing Suikoden I and II HD Remaster.exe and GameAssembly.dll. In Steam, use Manage → Browse local files to find it. Setup checks the supported game build and reports conflicting loader or duplicate plugin files.

  3. Choose whether to install the S1 battle preview

    Select Experimental S1 ATB / CTB (installed disabled) to install the component. Standard battles are the default. Enable your chosen battle mode in the launcher. See optional features before turning it on.

  4. Open the launcher and apply your settings

    Open Stars of Destiny in the current user’s Start Menu, or run <game>/StarsOfDestiny Launcher/StarsOfDestiny.Launcher.exe. Choose Suikoden I or II, then set your seed and options. To use a website preset, follow the steps below.

    With the game closed, select Apply settings or Save & launch game.

  5. Let first-run setup finish

    Keep Steam and internet access available while BepInEx downloads reference libraries and generates interop files. The first launch can take several minutes; wait for the title screen.

  6. Start your adventure

    Choose the matching game and start New Game to use the new seed, roster, start, weapon and joining-inventory policies. The F6 panel starts hidden; press F6 to cycle its text through Full, Compact and Hidden views.

Upgrading an existing installation

Setup preserves existing settings, campaign bindings, saves and unrelated plugins. Fresh defaults do not overwrite your choices. Leaving the optional battle component unchecked preserves an existing installation of that component. Keep the transaction backup path printed by setup so you can undo that installation later.

Manual ZIP installation

The mod-only ZIP includes the randomizer, complete launcher, Suikoden Fix and the dormant S1 ATB / CTB preview. It requires BepInEx separately and does not run the setup installer.

  1. Close the game and launcher and back up Save together with BepInEx/config.
  2. For a fresh mod installation, extract the tested BepInEx 6 IL2CPP Windows x64 build 697 into the game folder, launch the game once to prepare its references, then close it. Keep an already working matching loader.
  3. Extract the mod ZIP into a temporary folder and read its START HERE.txt. For an upgrade, follow StarsOfDestiny Manual/MANUAL UPGRADE.txt: preserve existing CFGs and campaign sidecars before copying mod files into the game folder. Do not replace an existing configuration folder with fresh defaults.
  4. Keep one randomizer and Fix copy, and at most one active battle preview copy if installed. Copy the complete launcher folder, then review and apply your settings with the game closed.

Manual copying does not create an installer recovery transaction. Keep the manual backup and package file list for undo. Activate the optional battle preview through the launcher to try ATB or CTB.

The plugins-only Nexus ZIP supplies plugins, defaults and manual settings instructions without launcher EXEs or a runtime. Install BepInEx separately and edit the CFG files by hand, or add the optional launcher 1.0.7. For a launcher-only upgrade, close the game and launcher, back up the old launcher folder/preferences, then replace its entire folder beside the game EXE.

Use a website settings preset

  1. In the website settings builder, choose the game, seed, mode, companions, start, joining weapon level and joining inventory, then download the settings preset JSON.
  2. Install 0.14.6 and open its launcher. Choose Load settings… and select the downloaded JSON.
  3. Select the game you configured, review its options, then choose Apply settings or Save & launch game while the game is closed.
  4. Start a New Game in that game.

The preset carries the selected game’s basic campaign choices. The launcher provides the rest of the settings, including dialogue, interface, treasure, S1 quality-of-life switches and optional ATB / CTB controls. Loading a preset merges its supplied options; it does not replace your other game’s settings or saved campaign bindings.

Downloading a preset does not apply it. The full installer installs its defaults or preserves existing configurations; it does not read a loose configuration file placed beside the setup EXE.

Seeds & saved games

Suikoden I and II use separate seeds, mappings and settings. Seed, roster, quick start, joining weapon and joining inventory choices apply to new campaigns. Existing randomized saves restore their own seed, cast and weapon policy, including earned sharpening. Saves created before joining-equipment balancing keep their previous inventory policy; upgrading does not replace earned gear.

Starting New Game may replace the shared autosave. Make a manual save and keep a paired backup of Save and BepInEx/config first. Do not delete campaign sidecars to force a different seed or weapon policy onto a saved run.

Ordinary saves are not converted into new randomized campaigns. If a randomized save has lost its binding, restore the matching configuration backup rather than generating a new campaign over it.

Modes, starts & joining weapons

  • Character shuffle assigns eligible combat fighters to story roles using your seed. Protagonist shuffle is optional.
  • Fixed roster reserves the protagonist and lets you choose five different companions. Story progression still determines how many active party slots are available.
  • Random roster uses the seed to choose five companions alongside the protagonist.

Recruitment requirements and story roles stay native. Names, portraits, party and combat appearances follow the replacements; some custom scene animations retain native handling. Supported English dialogue mentions use shuffled names, while ambiguous references, other languages and unsupported messages stay original.

Native shuffled-character Unite previews follow the actual fighters in your party, including replacements occupying unrelated story roles. Participants still need to satisfy each attack’s native conditions. Use normal turn-based battles for these Unites.

Joining inventory & equipment

The fresh default in both games is Original role's starting inventory. On a replacement's first party join, it copies the original story character's armor, accessories and carried items, including consumables. Incompatible gear is replaced with comparable equipment the new fighter can wear.

This works with Character shuffle, Fixed roster and Random roster. Choose Replacement's starting inventory to retain the previous behavior. Weapon identity, runes and the separate joining weapon-level option keep their own handling.

The policy is saved with the campaign and applies once. Later joins preserve acquired items and player equipment changes. Existing campaigns keep their saved policy: saves made before this feature retain the previous replacement-inventory behavior. Start a new campaign to use the new default.

Suikoden I inventory and quick start

In Suikoden I → Quality of Life, each of the following is enabled by default. Uncheck individual options or select Disable all four, then choose Apply settings with the game closed.

  • Roc’s Warehouse. After recruiting Roc, open Items → Roc’s Warehouse below Party Items to deposit or withdraw items from the field.
  • Shared battle items. Select Item to use a battle item carried by any living fighter in the active party, including Unbalanced allies. The carrier’s stack spends the charge.
  • Optimize equipment. In Equipment, choose a fighter and press Up from headgear. Press Left or Right on Optimize to select own pockets, party, own pockets plus warehouse, or party plus warehouse. The default searches loose party gear and adds warehouse stock once Roc joins. Gear worn by teammates stays equipped.
  • Match starting companions to Tir. A new Viktor quick start raises the two starting teammates to Tir’s checkpoint level, normally 7, using each fighter’s own stat growth.

Optional features

Suikoden I treasure shuffle

Experimental and off by default. In launcher 1.0.7, tick Enable chest shuffle for new campaigns in Treasure settings before starting a new game. Protected recruitment items, potch and special rewards stay original. Existing saves keep their own chest policy; unchecking the new-campaign option does not pause an existing shuffled save.

To change an existing save, choose checked for shuffled rewards or unchecked for original rewards, select Apply settings, select its snapshot in Saved campaign chest settings, then click Reset selected save’s chest settings. The next load adopts that choice. The manager backs up the old policy; acquired items and opened chest flags stay intact. Applying settings in 1.0.7 also clears a global chest pause left by an older launcher. Suikoden II chest randomization is not included.

Suikoden I CTB preview 0.5.2

CTB pauses while you choose a command and shows the next eight actions at the bottom of the screen. SPD and the action taken determine when a fighter returns. On consecutive party turns, the next full command menu can open while the previous animation plays.

  1. Close the game. In the launcher, open Suikoden I → Battle & ATB, clear Enable shuffled-character Unite attacks and, if previously enabled, turn off the legacy Talisman preview in Advanced. If the component is dormant, select Activate ATB / CTB preview.
  2. Check Enable battle preview component and Enable CTB (overrides ATB). Select Apply settings. Break and Reserve Rally have individual switches.
  3. Choose Open CTB tuning editor to adjust Star and enemy SPD, Break delays, or optional adaptive scaling. Solo-boss Break defaults to 25% of the boss’s normal turn interval. The tested solo-boss blend uses 75% party SPD and 25% recommended-level SPD.

To restore standard battles, clear both CTB and the battle preview component and apply. To use ATB’s filling SPD meters instead, enable the component with CTB off and select the ATB options you want. Duels, army battles and Suikoden II retain their usual battle systems. CTB guide and tuning details →

Troubleshooting & restore

First launch is slow, or no F6 panel appears

Wait for BepInEx’s first-run reference download and interop generation. Check BepInEx/LogOutput.log for progress or errors. Once in-game, focus the window and press F6: hidden is the default, and visible modes show text without a black box. The launcher can change the startup view.

My seed, quick start or joining equipment did not change

Load the website JSON with Load settings…, apply it in the launcher with the game closed, and start New Game in the selected game. Existing saves keep their bound seed, policy and progress. Upgrades preserve existing configuration choices, so select Riou’s ±3 option explicitly for a new S2 campaign if an older policy was retained.

Setup reports a loader conflict or duplicate plugin

Keep a backup before changing anything. Do not mix different BepInEx core or runtime versions. A renamed folder under BepInEx/plugins still loads its DLLs; duplicate randomizer, ATB or Fix copies must be moved outside that plugins tree. Follow the reported conflict rather than bypassing setup’s checks.

How do I undo this installation?

Close the game and launcher. Open the Start Menu support shortcut or <game>/StarsOfDestiny Setup, then run Restore.cmd. Supply the FullPreview-* transaction backup path printed by setup under <game>/SRR-Backups. Restore checks each recorded file and its backup. If setup stopped midway, use the transaction path printed when setup began. After a Steam update, restore can remove matching package files and keeps older loader and plugin binaries in the backup. If a later transaction or edit conflicts, follow its message or undo later transactions first.

Restore does not rewind gameplay or undo later settings edits. For a whole campaign restore, use its paired Save and BepInEx/config backup. Launcher configuration backups are under BepInEx/config/StarsOfDestiny.Launcher/backups.

This release was verified with game interop builds, managed gameplay fixtures, launcher checks and package tests. It has no new in-game playtest. When reporting an issue, include S1/S2, versions, seed, mode, scene and BepInEx/LogOutput.log.
