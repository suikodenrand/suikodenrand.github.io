What you need

  • A Windows 64-bit copy of Suikoden I & II HD Remaster. The randomizer works with Suikoden I.
  • BepInEx 6 for Unity IL2CPP, Windows x64, installed in the game folder.

Keep a separate backup of your saves before playing.

Installation

  1. Back up and close the game

    Close the game and back up your saves and BepInEx\config folder.

  2. Prepare BepInEx

    Skip this step if BepInEx is already working. Download the BepInEx 6.0.0-pre.2 Unity IL2CPP Windows x64 build and extract it beside Suikoden I and II HD Remaster.exe.

    Launch the game once and let the first-run setup finish. Close it, then check that BepInEx\interop\GSD1.dll exists.

  3. Choose your adventure

    Enter or roll a seed, then select a game mode and start point. Balanced starting gear is on by default; turn it off to use each hero’s original gear. Open the generator →

    Choose whether to include a spoiler file, then select Build installer ZIP.

  4. Extract and install

    Extract the entire ZIP. Open StarsOfDestiny-Setup.exe, select the folder containing Suikoden I and II HD Remaster.exe, and follow the setup prompts. Keep the generated configuration file beside Setup so it can install your settings. The current installer is unsigned.

  5. Start playing

    Launch Suikoden I and start a New Game to use your selected settings.

Seeds & saved games

Seed, roster, starting gear, and start point settings apply when you start a New Game. Existing randomized campaigns keep their saved roster and story progress.

Keep each randomized save with its matching BepInEx\config backup. Ordinary unmodified saves cannot be converted into randomized campaigns. Starting a New Game uses the game’s shared autosave, so keep a manual backup first.

Game modes & start point

  • Character shuffle assigns combat heroes to story roles based on the seed. Enable Include Tir in the shuffle to add the protagonist.
  • Fixed roster includes Tir automatically. Choose five different heroes from the list. When a companion slot opens, the game uses the first available fighter from your ordered list.
  • Random roster includes Tir and five different companions drawn from the seed. The same seed gives the same roster and order.

Story events determine how many companion slots are active. Ted, Odessa, and non-combat characters are outside the selection pool. Story events, dialogue, and voices follow the original roles. Names, portraits, appearances, and combat abilities follow the assigned fighters. Some Unite attacks are unavailable when characters have changed.

Balanced starting gear matches incoming weapon levels and compatible armor to the original story character’s starting gear. Six-hero rosters start with equipment suited to the opening. Runes, stats, and character levels keep their usual behavior. Turn this option off for each hero’s original starting gear.

Choose Before Viktor with any mode to begin in Gregminster after the inn scene. The protagonist has the Soul Eater and Viktor is waiting to join. Choose Normal Opening for the usual start.
