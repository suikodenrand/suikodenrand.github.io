What you need

  • A Windows 64-bit copy of Suikoden I & II HD Remaster. The randomizer works with Suikoden I.
  • BepInEx 6 for Unity IL2CPP, Windows x64, installed in the game folder.
  • An Internet connection for setup to download any required tools.

This is a test version. Keep a separate backup of your saves before playing.

Installation

  1. Back up and close the game

    Make a manual save, then close the game completely. Back up your save folder and, if present, the entire BepInEx\config folder together. Windows saves are usually in Save\(USER_ID) inside the game folder. Keep the backups in a separate location.

  2. Prepare BepInEx

    Skip this step if BepInEx is already working. Download the BepInEx 6.0.0-pre.2 Unity IL2CPP Windows x64 build and extract it beside Suikoden I and II HD Remaster.exe.

    Launch the game once and let the first-run setup finish. Close it, then check that BepInEx\interop\GSD1.dll exists.

  3. Choose your adventure

    Enter a seed or roll a random one, then select your game mode and start point. Seeds accept 1–128 characters, excluding backslashes. Open the generator →

    Choose whether to include a spoiler file, then select Build installer ZIP.

  4. Extract and install

    Use Windows Extract All to unpack the entire download into a fresh folder. Double-click Install.cmd and select your game folder when prompted.

    Setup prepares the plugin, applies your chosen settings, and backs up the files it changes. The first installation may take a few minutes while tools download. Wait for the installation-complete message before starting the game.

  5. Start playing

    Launch Suikoden I and start a New Game to use your selected settings.

Seeds & saved games

Seed, roster, and start point settings apply when you start a New Game. Existing randomized campaigns keep their saved roster and story progress.

Keep each randomized save with its matching BepInEx\config backup. Ordinary unmodified saves cannot be converted into randomized campaigns. Starting a New Game uses the game’s shared autosave, so keep a manual backup first.

Game modes & start point

  • Character shuffle assigns 75 combat heroes to story roles based on the seed. A hero may draw itself.
  • Fixed roster includes Tir automatically. Choose five different heroes from the list. When a companion slot opens, the game uses the first available fighter from your ordered list.
  • Random roster includes Tir and five different companions drawn from the seed. The same seed gives the same roster and order.

Story events determine how many companion slots are active. Ted, Odessa, and non-combat characters are outside the selection pool. Story events, dialogue, and voices follow the original roles. Names, portraits, appearances, and starting combat setups follow the assigned fighters. Some Unite attacks are unavailable when characters have changed.

Choose Before Viktor with any mode to begin in Gregminster after the inn scene. Tir has the Soul Eater and Viktor is still waiting to join. Choose Normal Opening for the usual start.

Quick check

If you picked Before Viktor, confirm you start in Gregminster and can recruit him. Check your party’s names and portraits, then complete an ordinary battle. Make a manual save, fully quit, and reload to confirm the cast and your progress stay the same.

Troubleshooting

Setup stops or reports an unsupported game version

Keep the installer log shown by setup. Confirm you selected the correct game folder and that BepInEx has finished its first launch. Report the message and log if setup still fails.

My settings did not take effect

Start a New Game to use your new roster, seed, or start point. If the wrong version loads, check for duplicate randomizer files or an older installer folder.

A battle stalls or another problem occurs

Press F6 to record a checkpoint if the game responds, then close it. Run Collect-Avatar-Diagnostics.cmd from your extracted installer folder and select the game folder. Send the resulting Desktop ZIP with a short description of what happened. Reload an earlier save after a stalled battle.

Suikoden Fix is optional. If you use it, keep the original release and remove older modified copies that contain another randomizer.

Undo an installation

Close the game and run Rollback.cmd from the same extracted package. It restores the previous plugin files and randomizer configuration, or removes files created by a first installation. It does not restore your game saves; use your own backup for those.
