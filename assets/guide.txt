STARS OF DESTINY - CHARACTER RANDOMIZER
Setup guide / Version 0.8.7 / Windows x64
https://suikodenrand.github.io/#generate

WHAT YOU NEED

- A Windows 64-bit copy of Suikoden I & II HD Remaster.
- BepInEx 6 for Unity IL2CPP, Windows x64, installed in the game folder.

INSTALLATION

1. Close the game and back up your saves and BepInEx\config folder.
2. If BepInEx is new to you, download the 6.0.0-pre.2 Unity IL2CPP Windows x64 build and extract it beside Suikoden I and II HD Remaster.exe. Launch the game once and close it.
   https://github.com/BepInEx/BepInEx/releases/tag/v6.0.0-pre.2
3. Choose a seed, mode, and start point on the website. Select Build installer ZIP.
4. Extract the entire ZIP. Keep the configuration file beside StarsOfDestiny-Setup.exe. Open Setup, select the folder containing Suikoden I and II HD Remaster.exe, and follow the prompts. The current installer is unsigned.
5. Launch Suikoden I and start a New Game.

MODES & START POINT

- Character Shuffle uses the seed to shuffle combat heroes into story roles. Enable Include Tir in the shuffle to add the protagonist.
- Fixed Roster uses Tir and the five companions you select.
- Random Roster uses Tir and five companions drawn from your seed.
- Before Viktor starts in Gregminster after the inn scene. Recruit Viktor to continue.

Seed, roster, and start point settings apply to New Game. Existing randomized saves keep their saved roster and story progress. Keep each randomized save with its matching BepInEx\config backup.
