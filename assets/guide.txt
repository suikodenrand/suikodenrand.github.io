STARS OF DESTINY 0.14.4 - SETUP GUIDE
Suikoden I & II HD Remaster | Steam | Windows x64
https://suikodenrand.github.io/

FULL INSTALLER
1. Close the game and launcher. Back up Save and BepInEx/config together
   outside the game folder. Keep the pair for your campaign.
2. Download and run Stars-of-Destiny-0.14.4-r2-Setup.exe. Select the folder
   containing Suikoden I and II HD Remaster.exe and GameAssembly.dll.
   In Steam use Manage > Browse local files to locate it.
3. Leave optional Experimental S1 ATB unchecked for standard turn-based
   battles. Installing ATB does not enable it.
4. Open Stars of Destiny from the Start Menu or run
   <game>/StarsOfDestiny Launcher/StarsOfDestiny.Launcher.exe.
5. Choose S1 or S2, seed and options, then Apply settings or Save & launch
   game while the game is closed. Keep Steam and internet available for
   BepInEx's first reference download and interop generation.
6. Choose the matching game and start New Game. F6 starts hidden and cycles
   Full, Compact and Hidden text views.

The full installer includes BepInEx 6 IL2CPP Windows x64 build 697,
Suikoden Fix, the combined randomizer and complete launcher 1.0.5.
Package revision 2 changes the launcher and package instructions, not the
released randomizer or gameplay defaults. Their
private runtimes are included; no separate .NET SDK or compiler is needed.

MANUAL ZIP
The mod-only ZIP requires the tested BepInEx loader separately. For a
fresh installation, extract the loader into the game folder, launch once
and allow setup to finish, then close the game. Keep a working matching
loader when upgrading.
Extract the mod ZIP into a temporary folder. Read START HERE.txt and
StarsOfDestiny Manual/MANUAL UPGRADE.txt before copying into an existing
installation. Preserve existing CFGs and all campaign sidecars. Copy the
complete launcher folder, not only its EXE. Keep one randomizer/Fix copy and at most one active ATB copy if installed. Manual copying creates no installer restore transaction; retain
its backup and file list for undo.

WEBSITE SETTINGS PRESETS
The website exports a JSON settings preset for the selected game. In
launcher 1.0.5 use Load settings..., select the JSON, review the game and
options, then Apply settings or Save & launch game. Downloading a preset
does not apply it; setup does not read a loose config beside its EXE.
The preset merges only its supplied options and preserves unrelated
settings, the other game's choices and saved campaign bindings.

MODES, STARTS AND JOINING EQUIPMENT
Both games offer seeded Character shuffle, five chosen companions, and a
seeded Random roster. Story progression still controls active party size.
Optional protagonist shuffle is available. The normal opening is the
fresh default; S1 can start before Viktor joins and S2 at Viktor's camp.
New campaigns default to the original story role's full starting inventory,
including armor, accessories and consumables. Incompatible gear gets a
comparable wearable replacement. This works in all three character modes,
initializes once, and preserves later equipment changes and acquired items.
Choose Replacement's starting inventory to retain the previous behavior.
Weapon identity and runes keep their own handling. The separate default
joining weapon level follows Tir in S1 or Riou in S2 with seeded -3 to +3
variance. Original-role and Level 1 options are also available.

SAVES AND UPGRADES
Keep Save and BepInEx/config together. Existing campaigns retain their
saved seed, cast, policies and progress; upgrading does not retrofit gear.
Start a New Game to use a new inventory policy. New Game may overwrite the
autosave, so make a manual save and paired backup first. Never delete
campaign sidecars to force new settings onto an old save.

OPTIONAL S1 FEATURES
Chest shuffle is experimental and off by default. In Treasure settings,
tick Enable chest shuffle for new campaigns before a new game. Existing
saves retain their own chest policy when this checkbox changes.
To change an existing save, choose checked for shuffled rewards or unchecked
for original rewards, Apply settings, select its snapshot, then Reset selected
save's chest settings. Load that save to adopt the policy. Its prior policy
is backed up; acquired items and opened chests stay intact. Applying settings
in launcher 1.0.5 also clears a legacy global pause left by older launchers.
ATB is optional and experimental. Disable S1 shuffled Unites before enabling
ATB in Battle & ATB. For a dormant manual ZIP installation, first click
Activate ATB preview after disabling S1 shuffled Unites, then enable ATB and
Apply settings. Skip activation when setup already installed ATB. Native
SPD meters and individual commands replace the
normal turn flow. Disable ATB before re-enabling shuffled Unites.
S2 ATB, S2 chest shuffle and Nuzlocke are not included.

HELP AND RESTORE
For slow first launch or missing F6, inspect BepInEx/LogOutput.log and allow
reference generation to finish. The F6 view is hidden by default.
For unchanged options, apply the preset with the game closed and use New
Game; existing saves retain their own policies.
Do not mix BepInEx core/runtime versions. Renaming a folder inside
BepInEx/plugins does not disable its DLLs; keep backups outside plugins.
To undo a full setup transaction, close the game and launcher and run
<game>/StarsOfDestiny Setup/Restore.cmd with the printed FullPreview-*
backup path under SRR-Backups. Undo later transactions first when required.
This does not rewind gameplay or replace a paired campaign backup.
For manual installs, restore the matching manual backup and remove only
newly added package files. Older setup recovery does not undo a later
manual upgrade.
